🚀 Быстрый старт (кратко)
bash
# 1. Клонировать проект
git clone https://github.com/Erxn1/finance_tracker.git
cd finance_tracker

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
# Для Linux/macOS:
source .venv/bin/activate
# Для Windows:
.venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить приложение
python main.py
📝 Подробное руководство
1. Получение кода проекта
Откройте терминал (командную строку) и выполните команду для копирования проекта с GitHub:

bash
git clone https://github.com/Erxn1/finance_tracker.git
После этого перейдите в созданную папку:

bash
cd finance_tracker
2. Создание виртуального окружения (изоляция зависимостей)
Виртуальное окружение — это изолированная среда Python для вашего проекта. Она предотвращает конфликты версий библиотек между разными проектами.

Создайте окружение в папке проекта:

bash
# Убедитесь, что используете Python версии 3.8 или выше
python -m venv .venv
Активируйте его:

Windows (PowerShell):

powershell
.\.venv\Scripts\Activate.ps1
(Если возникнет ошибка выполнения скриптов, запустите PowerShell от имени администратора и выполните: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser, затем повторите активацию).

Linux/macOS:

bash
source .venv/bin/activate
Признак успешной активации — появление имени окружения (.venv) в начале строки терминала.

3. Установка необходимых библиотек
Все библиотеки, которые использует проект (pandas, matplotlib, tkinter), перечислены в файле requirements.txt. Установите их одной командой:

bash
pip install -r requirements.txt
Важно: Убедитесь, что виртуальное окружение активировано, иначе библиотеки установятся глобально и могут возникнуть конфликты.

4. Запуск приложения
Когда зависимости установлены, запустите главный файл:

bash
python main.py
Должно открыться главное окно приложения с интерфейсом Tkinter.

5. Запуск тестов
Проект содержит тесты в папке tests/. Для их запуска используется фреймворк pytest.

Убедитесь, что виртуальное окружение активировано и установлен pytest (он есть в requirements.txt). Запустите все тесты из корневой папки проекта:

bash
pytest
Pytest автоматически найдет и выполнит все файлы, имена которых начинаются с test_ или заканчиваются на _test.py.

6. Деактивация окружения
Когда работа над проектом завершена, выйдите из виртуального окружения командой:

bash
deactivate
